# 评测方法与复现

## 检索质量

固定文档语料、解析版本、切分参数、embedding 模型、召回数量和重排配置。问题按模型名称、缩写、论文标题、方法解释和跨文献比较分类，人工标注相关证据片段。

对比稠密召回、双路召回、融合与精排等配置，逐题保存召回 ID 和排序。报告 Recall@K、MRR 及各类问题分项结果。数据集分为调参集和留出测试集，问题改写与同一原始问题分在同一组。

## 证据与回答

- 引用可定位：引用编号能够解析到本次任务中的证据项。
- 来源可核验：证据中的文档与片段 ID 对应到实际内容。
- 引用支持度：原文是否支持回答中的具体断言，由人工复核或经过校准的评审模型判断。
- 正确拒答：对标注为无法由当前知识库回答的问题，检查系统是否明确限制结论。

可定位率、引用支持率和正确拒答率分别统计，报告各自分母及失败原因。

## 研究任务

记录问题、计划、证据缺口、补查次数、外部委托、最终引用、耗时和模型消耗。检查终止预算、工具权限、状态恢复及检索异常处理。

## 代码验证

Java 测试位于 `src/test`，Python 测试位于 `python-runtime/tests`。前端执行 `npm run build` 验证生产构建。端到端验证使用自己的文献和服务配置，结果保存到本地评测目录。
